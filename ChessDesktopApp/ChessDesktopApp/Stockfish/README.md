# Stockfish

Umieść w tym folderze lokalny plik wykonywalny Stockfisha, najlepiej pod nazwą
`stockfish.exe`. Aplikacja wybierze również pierwszy plik `*stockfish*.exe` znaleziony
w tym katalogu.

Alternatywnie ustaw zmienną środowiskową `CHESS_STOCKFISH_PATH` na pełną ścieżkę do
pliku EXE. Zmienna środowiskowa ma pierwszeństwo.
